# خريطة الشاشات والتخطيط

المرحلة 2 — 9 أكتوبر 2026. [المعاينة التفاعلية](D:/Projects/Portfolio/phases/results/02/prototype/index.html) تستخدم روابط hash للتنقل المحلي فقط، وليست قرارًا نهائيًا لمسارات استضافة Flutter.

## الشاشات العامة

| رمز النموذج | الصفحة | ترتيب المحتوى والإجراء |
| --- | --- | --- |
| home | الرئيسية | هوية ← رسالة وتكوين بصري ← استكشف كل الأعمال ← مدخل أنواع الحلول والخدمة ← طلب مشروع ← فوتر |
| work | الأعمال | عنوان ← بحث ← تصنيفات ← كل البطاقات ← حالة بحث فارغ عند الحاجة |
| project/Pxxx | تفاصيل مشروع | عودة ← عنوان وتصنيف ← صورة وتكبير ← احتياج وحل ووظائف ومساهمة ← فيديو اختياري ← طلب مشابه |
| services | خدماتنا | الخدمة المؤكدة ← أمثلة الأعمال ← بدء طلب؛ لا منصات تخصصية مخمنة |

كل صفحة لها هيدر وفوتر مناسبين، وتبديل لغة ووضع ثابت المكان. الثلاث بطاقات الافتتاحية مدخل إلى الـ15؛ ليست قائمة استبعاد لباقي الأعمال. العدد يتوسع من البيانات لاحقًا.

## شاشات الأدمن

| رمز النموذج | الصفحة | المهمة الرئيسية |
| --- | --- | --- |
| login | دخول الفريق | حقول واضحة وزر دخول؛ المزود لم يثبت والنموذج توضيحي |
| admin | نظرة عامة | أعداد النموذج، أعمال تحتاج استكمالًا، إضافة مشروع |
| admin/projects | المشاريع | حالات وتعديل ومعاينة؛ على الهاتف تتحول الصفوف لكروت |
| admin/editor/Pxxx | المحرر | محتوى ← صور وملفات ← نشر وروابط، وملخص جاهزية وحفظ ومعاينة ونشر |
| admin/media | مكتبة الوسائط | صور وملفات وارتباطاتها، رفع ومعاينة وإعادة استخدام |
| admin/categories | التصنيفات | تسميات عربية/إنجليزية، عدد ارتباطات، إضافة وتعديل |
| admin/team | الفريق | حالة فارغة ثم نموذج أسماء وأدوار ونبذة وصورة وترتيب وظهور |
| admin/company | الشركة والتواصل | نبذة باللغتين وقنوات اتصال فارغة حتى يدخلها المستخدم |

| states | مرجع الحالات | تحميل، صورة مفقودة، رفع، لغة ناقصة، تعديل منشور، فشل حفظ، أرشفة وحركة |

معرض التكبير ونافذة المعاينة نوافذ داخل السياق، وليسا وجهة تنقل رئيسية بديلة للصفحات. إغلاق Escape وعودة التركيز إلى المشغّل جزء من التصميم.

## تخطيط افتتاحية الكمبيوتر

| المستوى | جانب البداية حسب اتجاه اللغة | جانب النهاية |
| --- | --- | --- |
| الهيدر | اللوجو ثم التنقل | لغة، وضع، ابدأ مشروعك |
| المقدمة | تعريف صغير، عنوان على سطرين، وصف قصير، إجراء أساسي وثانوي | شاشة عمل داخل إطار، شريط هوية خلفها، تعليق بصري |
| الأعمال | عنوان قسم وتفسير | رابط جميع الأعمال |
| الشبكة | ثلاثة كروت بنفس بنية الصورة والنص | كل كارت يقود للتفاصيل |

العربية تبدأ من اليمين والإنجليزية من اليسار؛ لا يعكس اللوجو أو محتوى شاشة المشروع. نصوص الإنجليزية لا تحتاج ترتيبًا يدويًا مخالفًا لترتيب القراءة.

## تخطيط الهاتف

1. هوية + لغة + وضع + زر قائمة، ثم روابط التنقل عند فتحها.
2. تعريف صغير، عنوان ملتف طبيعيًا، وصف، أزرار في مساحة مريحة.
3. التكوين البصري بصورة واضحة وحركة مخففة، ثم مدخل الأعمال.
4. عمود واحد للكروت؛ التصنيفات تلتف دون تمرير أفقي مفروض.
5. صفحة المشروع: الصورة ثم المحتوى ثم طلب مشابه؛ لا عمود جانبي ضيق.
6. الأدمن: روابط ملتفة ثم المحتوى، نموذج عمود واحد وملخص جاهزية بعده. أزرار الحفظ والمعاينة والنشر في صفوف مرنة.

## التخطيط الوظيفي للمحرر

النموذج يستخدم تبويبات مهمة لا تبويبات لغة تخفي نقصًا: المحتوى / الصور والملفات / النشر والروابط. داخل المحتوى تعرض حقول العربية والإنجليزية متجاورة على الكمبيوتر ومتتالية على الهاتف، مع تسمية اتجاه كل حقل. التفاصيل الأساسية في الإنتاج تفصل احتياجًا وحلًا ووظائف ومساهمة وفق عقد 1؛ خانة التفاصيل الكبيرة في المعاينة موضع تمثيلي لهذه المجموعة.

ملخص الجاهزية يقابل النموذج في الكمبيوتر؛ ينتقل أسفل الحقول عند ضيق العرض. آخر حفظ، نسخة عامة موجودة، ونقص النشر معلومات ظاهرة. «حفظ مسودة» لا يعني نشرًا، و«نشر التعديلات» يوضح تحديث النسخة العامة.

## مسارات المراجعة

- home ← work ← project/P008 ← طلب حل مشابه ← contact مع P008 محفوظًا في سياق الطلب.
