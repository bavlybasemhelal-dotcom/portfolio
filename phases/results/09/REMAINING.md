# حدود إغلاق المرحلة 9

هذه قائمة شروط متبقية، ولا تعني بدء مرحلة أخرى.

في 12 أكتوبر طلب المستخدم إيقاف الاختبارات والاستمرار في تعديل التصميم. لذلك لا تطلب تجربة هاتف أخرى حاليًا، ولا تعتبر مرور الوقت إذنًا لاستئناف الفحوص.

| البند | ما يحتاج استكمالًا |
| --- | --- |
| آخر تعديل | توزيع المعاينات على ستة مواضع نفذ في المصدر؛ لم تجر اختبارات أو مراجعة بصرية بعده، وتجهيز البناء لا يثبت صحة العرض |
| التحليل والتراجع | آخر analyze لم يكتمل؛ 138 اختبارًا و27 مستهدفًا سبقت تعديل المواضع؛ تراجع آخر تعديل لاحقًا عند إعادة الاختبارات |
| العرض المستقر | إعادة التقاط ومراجعة المصفوفة بعد اكتمال الانتقالات؛ 72 لقطة خام لا تصلح كلها لاعتماد العرض |
| لوحة المفاتيح | نموذج التواصل جرب؛ المعرض والتفاصيل في المتصفح النهائي متبقيان |
| محتوى الأعمال الحقيقي | المرحلة 8 ما زالت تفتقد الوصف والمساهمة والنوع والروابط والصور المعتمدة للأعمال؛ 15 مسودة خاصة لا تنشر دون هذه المعلومات |
| ميزانية الأداء | قياسات أولية تجاوزت 5 ثوانٍ؛ 3 زيارات أولى و3 متكررة وقياس التفاعل على آخر بناء متبقية، مع توثيق اختلاف المتصفح والشبكة |
| المتصفحات | التحقق الحالي داخل IAB وAndroid Chrome لا يثبت إعادة مراجعة Chrome وEdge المكتبيين في المرحلة 9؛ نتائج المراحل السابقة تبقى تاريخية |
| قارئ الشاشة | شجرة وصول وتركيز ولوحة مفاتيح لا تستبدل اختبار Narrator/TalkBack فعليًا |
| الأجهزة الأصلية | APK المبني لا يثبت تشغيل تطبيق Android أصلي؛ iOS/macOS/Linux لم تختبر، وWindows مؤجل بأمر المستخدم |
| الفيديو | حد الخدمة الحالي 5 MiB؛ لا رفع كبير أو بث seek للملفات الكبيرة أثبت هنا |
| الإطلاق والفهرسة | النطاق والاستضافة العامة وmetadata لكل رابط والـSEO من مراجعة 10، ولم تبدأ 10 |

يمكن إدخال المحتوى من الأدمن لاحقًا. لا توضع عينات الاختبار المعزولة باعتبارها أعمال الشركة، ولا تختلق نتائج أو بيانات تواصل.
