# قالب معلومات مشروع

ينسخ هذا القالب لمشروع جديد أو يستخدم لإكمال بطاقات [الحصر](D:/Projects/Portfolio/phases/results/01/PROJECTS.md). حالة كل حقل إحدى: متوفر / يحتاج المستخدم / يحتاج تحقق / اختياري. لا توجد قيم افتراضية تمثل عملًا حقيقيًا.

## التعريف والمصدر

| البيان | القيمة | الحالة والمصدر |
| --- | --- | --- |
| رمز الحصر أو مرجع المشروع | يملأ عند الحصر | مرجع داخلي؛ لا يكتب أنه معرف Firebase قبل إنشائه |
| الاسم بالعربية | لم يدخل | يحتاج المستخدم |
| الاسم بالإنجليزية | لم يدخل | يحتاج المستخدم؛ أي ترجمة مقترحة تحتاج تحقق |
| النوع / التصنيف | لم يدخل | يحتاج المستخدم أو تحقق إذا مستنتجًا |
| القطاع / الوسوم | لم يدخل | اختياري |
| حالة الاستخدام | لم تدخل | يحتاج المستخدم: فعلي / تجريبي / شخصي أو سابق |
| العمل باسم YOGEN أم مساهمة سابقة / شخصية | لم يدخل | يحتاج المستخدم |
| السنة / تاريخ التنفيذ | لم يدخل | اختياري |
| مصدر المعلومات ومن راجعها | لم يدخل | يحتاج المستخدم قبل النشر |

## النصوص

| الحقل | عربي | إنجليزي | الحالة |
| --- | --- | --- | --- |
| وصف مختصر للبطاقة | لم يدخل | لم يدخل | يحتاج المستخدم |
| المشكلة أو الاحتياج | لم يدخل | لم يدخل | يحتاج المستخدم |
| الحل | لم يدخل | لم يدخل | يحتاج المستخدم |
| الوظائف الأساسية | لم تدخل | لم تدخل | يحتاج المستخدم؛ يذكر الفعلي فقط |
| نطاق مساهمة YOGEN / الفريق | لم يدخل | لم يدخل | يحتاج المستخدم |
| نتائج أو شهادة | لم تدخل | لم تدخل | اختياري؛ المصدر وإذن العرض يلزمان عند الإدخال |
| عنوان ووصف بحث خاص | لم يدخلا | لم يدخلا | اختياري؛ يمكن اشتقاقهما من الاسم والوصف |

## الوسائط والروابط

| البيان | القيمة | الحالة |
| --- | --- | --- |
| غلاف منفصل صالح للعرض | لم يقدم | يحتاج المستخدم |
| وصف الغلاف البديل عربي / إنجليزي | لم يقدم | يحتاج المستخدم |
| صور المعرض وترتيبها ووصفها | لم تقدم | اختياري |
| فيديو وغلافه ووصفه | لم يقدم | اختياري؛ حدود الرفع بعد المرحلة 3 |
| مرفقات وعناوينها | لم تقدم | اختياري |
| رابط عرض عام كامل | لم يقدم | اختياري؛ يتحقق منه إذا أدخل |
| تقنيات مؤكدة | لم تقدم | اختياري |
| أعضاء مشاركون وأدوارهم | لم يقدموا | اختياري؛ ملفات الفريق العامة يمكن إضافتها لاحقًا |
| صلاحية عرض المحتوى والوسائط ونسبة العمل | لم تؤكد | يحتاج المستخدم قبل نشرها |

معرفات وروابط Drive وبيانات رفعها ينتجها نظام الرفع لاحقًا. لا تملأ يدويًا بروابط ملف متوقعة أو عنوان مبتور.

## فحص الجاهزية

- [ ] الاسم والوصف والمحتوى الأساسي والمساهمة مكتملة باللغتين ومراجعة.
- [ ] التصنيف وحالة الاستخدام ونسبة العمل مؤكدة.
- [ ] الغلاف مكتمل وصالح للعرض العادي داخل الموقع وله وصف بديل باللغتين.
- [ ] كل وسيط اختير للعرض انتهى رفعه وربطه؛ الروابط التي أُدخلت صالحة.
- [ ] عنوان صفحة المشروع فريد؛ حق العرض والمعلومات المنشورة واضحان.

حتى اكتمال هذه القائمة: يحفظ كمسودة. غياب الفيديو أو رابط تجربة أو التاريخ أو التقنيات لا يمنع النشر. التجربة الفعلية لملء القالب موثقة في [عينة برنامج المبيعات](D:/Projects/Portfolio/phases/results/01/SAMPLE-P001.md).
