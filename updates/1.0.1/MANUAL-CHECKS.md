# سيناريوهات غير منفذة — 1.0.1

جميع السيناريوهات التالية **غير منفذة** لأن المستخدم أوقف الاختبارات؛ لا تعد نتائج نجاح. تحفظ لتجربة مستقبلية عندما يطلبها المستخدم.

| السيناريو | المتوقع |
| --- | --- |
| ماوس / لمس على رمز الهوية | الضغط القصير والسحب إلى المربع يفتح تسجيل الدخول؛ الإفلات خارجه يرجع المجسم؛ التمرير السريع لا يبدأ سحبًا |
| تغيير حجم الصفحة واللغتين والمظهرين | المربع والتعليمات يبقيان داخل المقدمة، مع بقاء حركات المعاينات والمشاريع |
| البديل دون سحب | تحديد الشعار ثم مربع الدخول، أو Tab وEnter/Space، يصل إلى نفس تسجيل الدخول |
| زائر أو حساب غير مخول | لا أزرار حركة عامة ولا زر دخول الفريق؛ دخول /admin مباشرة يطلب حسابًا مخولًا |
| حساب مدير / محرر مخول | أزرار الحركة داخل الإدارة؛ تغيير كلمة المرور لحساب الجلسة فقط |
| كلمة حالية غير صحيحة | خطأ واضح دون تغيير الكلمة |
| تأكيد غير مطابق أو طول خارج 12–128 | منع الحفظ مع خطأ الحقل |
| حفظ كلمة جديدة صحيحة / انقطاع اتصال | تأكيد نجاح بعد Firebase، أو رسالة فشل دون ادعاء حفظ؛ كلمة المرور لا تكتب في Firestore/تقارير |
| دوران السكون والتمرير | لفة كاملة في 60 ثانية أثناء السكون، ودوران كامل بالتمرير؛ لا حركة مع تقليل حركة النظام |
| تحديث Android الأصلي | APK يثبت كتحديث بنفس الهوية والمفتاح؛ الدخول والبيانات مشتركة مع الويب |
